No account or login is required.

Attention turns a link into an image card (title, cover image, QR code) so it can be sent in chat apps that don't preview pasted links. Everything shared into it is also kept in a library on the device.

To test:
1. Copy a link (for example https://www.youtube.com/watch?v=0_DjDdfqtUE), open Attention and tap Paste in the toolbar. The link is saved and its preview appears in the library.
2. Tap the item to open it, tap Share and choose Share as Image, then pick the Card, Text or QR template. The card image goes to the system share sheet and the cleaned link is copied to the clipboard. Send the image to any chat app to see the result; the QR code opens the original link.
3. The share extension: in YouTube or Safari, open a video or page, tap Share and choose Attention. The link is saved to the library and can be shared as a card the same way.
4. Long-press an item for Open, Share, tags, Private and Delete.

The app reads public page metadata (title, preview image, icon) for the links the user saves. It uses public endpoints from YouTube (oEmbed), Bilibili and FxTwitter for richer previews of those sites, and Google's favicon service for site icons. Text in shared images is recognized on the device.

Optional visual search: Settings > "Download MobileCLIP" fetches a model file (about 100 MB) from the developer's GitHub Releases, with public mirrors as fallback. This is a one-time download that the user starts; the model then runs on the device. The library syncs through the user's own iCloud private database (CloudKit). No user data is sent to the developer.
